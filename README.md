# claude-skill-guard

נוהל חובה: כל סקיל או פלאגין של Claude חייב לעבור סריקת אבטחה לפני שמתקינים אותו או משתמשים בו.
הסריקה נעשית עם [SkillSpector](https://github.com/NVIDIA/skillspector) של NVIDIA (קוד פתוח, Apache 2.0).
היא ניתוח סטטי בלבד: שום קוד לא נשלח למודל או לשירות חיצוני.

הנוהל לא שייך לפרויקט מסוים. הוא מותקן פעם אחת ופועל בכל סשן של Claude Code, בכל ריפו.

## התקנה

### סביבת הענן של Claude Code (פעם אחת)

1. בסשן ענן, פותחים את תפריט הסביבה בשורת הכותרת ובוחרים Edit.
2. מוסיפים לשדה **Setup script** את השורות האלה:

   ```bash
   # skill-guard v3 (change the number so new sessions pick up updates)
   { if [ -d "$HOME/.skill-guard/.git" ]; then git -C "$HOME/.skill-guard" pull -q --ff-only
   else git clone -q --depth 1 https://github.com/shlomichai44/claude-skill-guard "$HOME/.skill-guard"; fi
   "$HOME/.skill-guard/install.sh"; } || echo "skill-guard setup failed; session continues without it"
   ```

3. שומרים. מעכשיו כל סשן חדש מתקין את הכלים ואת ההוקים, ומושך את רשימת המאושרים העדכנית.

- הסביבה שומרת את התוצאה של סקריפט ההתקנה ולא מריצה אותו שוב בכל סשן. לכן, אחרי שינוי בריפו הזה, מעלים את המספר בשורה הראשונה (v3, v4 וכן הלאה) ושומרים. השינוי גורם לסביבה להריץ את הסקריפט מחדש: היא מושכת את הגרסה האחרונה, מתקינה, וסורקת מראש, כך שהבדיקה בתחילת כל סשן לוקחת רק כמה שניות.
- הסוגריים המסולסלים ו-`|| echo` בסוף חשובים. בלעדיהם, תקלה בהתקנה מונעת מכל סשן חדש לעלות.
- הריפו צריך להיות ציבורי. סקריפט ההתקנה רץ עם גישה רק לריפו שנבחר לסשן, ולכן ריפו פרטי אחר לא ישוכפל. אין בריפו הזה סודות.

### מחשב מקומי

מריצים את אותן שלוש שורות בטרמינל. צריך `python3`, ‏`git` ו-[uv](https://docs.astral.sh/uv/).

## מה ההתקנה עושה

- מתקינה את SkillSpector בגרסה נעולה לקומיט שנבדק, ואת `model-signing`, שמאמת את החתימות של NVIDIA.
- יוצרת את הפקודה `skill-guard`.
- מוסיפה שני הוקים לקובץ `~/.claude/settings.json`, בלי למחוק הגדרות קיימות:
  - **בתחילת כל סשן:** כל סקיל ופלאגין מותקן נבדק. אם התוכן של סקיל לא תואם לרשימת המאושרים, הוא נסרק. אם הוא לא עובר, Claude מקבל אזהרה, מודיע לך ולא משתמש בו.
  - **לפני כל פקודת Bash:** התקנה של סקיל או פלאגין שלא נסרק באותו סשן נחסמת. זה חל על `npx skills add`, ‏`claude plugin install`, וגם על git clone, cp או unzip לתיקיית skills. אם המקור נסרק ולא עבר, תופיע לך בקשת אישור.

## התקנת סקיל חדש, צעד אחר צעד

1. לפני שלוחצים "התקן", מבקשים מ-Claude: "תסרוק את ‹שם הסקיל או קישור›".
2. Claude מריץ:

   ```bash
   skill-guard scan <מקור> [--skill <שם>] [--label <plugin@marketplace>]
   ```

   המקור יכול להיות תיקייה מקומית, כתובת git, או `owner/repo` ב-GitHub.
3. מחליטים לפי התוצאה:

   | תוצאה | מתי | מה עושים |
   |---|---|---|
   | **PASS** | SkillSpector מחזיר SAFE ואין ממצא בחומרה HIGH או CRITICAL | מתקינים |
   | **REVIEW** | ‏CAUTION (ציון 21–50), או שיש ממצא חמור | Claude בודק בקוד כל ממצא ומסביר אותו. מתקינים רק אם אתה מאשר במפורש |
   | **BLOCKED** | ‏DO NOT INSTALL (ציון 51 ומעלה), או שחתימת NVIDIA לא מתאמתת | לא מתקינים. חריג מותר רק אם כל ממצא חמור הוכח בקוד כהתרעת שווא, ואתה מאשר במפורש. לחתימה שנכשלה אין חריג |

4. סקיל שהיה REVIEW או BLOCKED ואושר נרשם אחרי ההתקנה ברשימת המאושרים:

   ```bash
   skill-guard approve <תיקיית הסקיל המותקן> --note "<מי אישר ולמה>"
   cd ~/.skill-guard && git commit -am "Approve <שם>" && git push
   ```

   Claude מריץ `approve` רק אחרי אישור מפורש שלך בצ'אט. בשביל ה-push, הסשן צריך הרשאת כתיבה לריפו הזה.

## פלאגינים וסקילים מותקנים

מה שרשום בקובץ `plugins.json` מותקן אוטומטית בכל סשן חדש, דרך `skill-guard install-plugins`. בתחילת הסשן נסרק גם העותק שהותקן בפועל.

- **פלאגינים** (`plugins`): לכל רשומה יש `plugin` בפורמט `name@marketplace`, ו-`marketplace` בפורמט `owner/repo`.
- **סקילים** (`skills`): לכל רשומה יש `source` בפורמט `owner/repo`, ‏`commit` (מזהה commit מלא), ‏`path` ו-`names`. ההתקנה נעולה ל-commit שנסרק, ולכן מה שמותקן הוא בדיוק מה שנבדק. כדי לעדכן, סורקים commit חדש ומחליפים את המזהה.

מוסיפים לרשימה רק אחרי סריקה שעברה, או אחרי שאישרת בצ'אט תוצאת REVIEW או BLOCKED.

כרגע ברשימה:
- **ffmpeg-llm** (של Rendi): כותב פקודות FFmpeg לפי בקשה במילים.
- **Remotion**, 12 הסקילים הרשמיים (`remotion-dev/skills@6c67adc`): יצירת סרטונים מקוד React. שלושה מהם (best-practices, ‏maps, ‏markup) קיבלו BLOCKED, נבדקו כהתרעות שווא ואושרו על ידך.
- **find-skills** של Vercel (`vercel-labs/skills@a80e4c9`): מחפש סקילים במאגר הפתוח skills.sh ומתקין אותם עם `npx skills`. עבר סריקה (PASS). החיפוש עובד רק אם `skills.sh` נמצא ברשימת האתרים המותרים של הסביבה.

## הערות לכל סשן

`skill-guard install-notes` מכניס את התוכן של `notes.md` לקובץ `~/.claude/CLAUDE.md`, כך ש-Claude קורא אותו בכל סשן. התוכן נכנס כבלוק מסומן, ושאר הקובץ לא משתנה. כרגע ההערה מסבירה איך מייצרים וידאו עם Remotion בענן: הרשת חוסמת את ההורדה של הדפדפן ש-Remotion צריך, ולכן משתמשים ב-Chromium שכבר מותקן.

## עדכונים

- כל אישור קשור לתוכן המדויק של הסקיל, לפי טביעת אצבע (hash). כשסקיל מתעדכן, הוא נסרק שוב.
- עדכון שלא מוסיף ממצאים חדשים עובר אוטומטית, ומסומן PASS-KNOWN.
- עדכון שמוסיף ממצא חדש חוזר לבדיקה.

## מגבלות

- התקנה דרך הממשק של claude.ai לא עוברת דרך Claude Code, ולכן אי אפשר לחסום אותה מראש. היא נבדקת רק בתחילת הסשן הבא, ולכן מבקשים סריקה לפני שלוחצים "התקן".
- SkillSpector מחפש תבניות חשודות. ציון נמוך הוא לא הבטחה שהסקיל בטוח, ויש גם התרעות שווא. דוגמה: הסקילים docx, ‏pptx ו-skill-creator של Anthropic מקבלים ציון גבוה בגלל קוד רגיל.
- החסימה של פקודות התקנה היא מעקה בטיחות ולא ארגז חול: היא מזהה רק את דרכי ההתקנה המוכרות.
- הסריקה הראשונה של סקיל גדול לוקחת עד דקה. סקיל מאושר שלא השתנה לא נסרק שוב.
- ההוק של תחילת הסשן רץ לפני שהסשן נפתח. כך מובטח שסקיל לא ישמש לפני שנבדק, אבל הפתיחה איטית יותר.

## הקבצים

- `skill_guard.py`: הסקריפט (הפקודות setup, ‏scan, ‏check, ‏approve, ‏install-hooks, ‏install-plugins, ‏install-notes, וההוקים). משתמש רק בספרייה הסטנדרטית של Python.
- `plugins.json`: פלאגינים וסקילים שעברו סריקה ומותקנים בכל סשן.
- `notes.md`: הערות שנכנסות ל-`~/.claude/CLAUDE.md` בכל סשן.
- `install.sh`: ההתקנה.
- `approved.json`: הסקילים שנבדקו ואושרו. לכל סקיל נשמרים השם, טביעת אצבע של התוכן והממצאים שאושרו.
- `trust/nvidia-agent-root.pem`: תעודת השורש של NVIDIA.

## עדכון SkillSpector

הגרסה נעולה לקומיט מסוים, בשני הקבועים `SKILLSPECTOR_SPEC` ו-`SKILLSPECTOR_VERSION` שבסקריפט. כדי לעדכן:

1. בודקים את הקומיט החדש ב-github.com/NVIDIA/skillspector.
2. מחליפים את שני הקבועים.
3. מריצים `skill-guard setup`, ואחר כך `skill-guard check`.
